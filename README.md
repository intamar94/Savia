# SAVIA

SAVIA is a native Godot project for a living ecosystem simulation game.

## v0.1

Initial foundation:
- Godot 4.7
- Mobile renderer
- 3D temperate-biome visual foundation
- Main menu
- Initial NORA placeholder
- Architecture ready for world, soil, plant, ecosystem, climate, laboratory and discovery systems

The game is designed around an integrated world: laboratory, perception, investigation and discovery are tools inside the same biome rather than disconnected screens.
